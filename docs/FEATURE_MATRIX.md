## Status Definitions
- **IMPLEMENTED**: Complete implementation in production code, backed by domain models, persistence, and passing automated unit/integration/E2E tests.
- **PARTIALLY_IMPLEMENTED**: Core engine/analyzer logic exists with unit tests, but full end-to-end API/UI wiring is incomplete.
- **FRONTEND_ONLY**: Element exists in UI template but has no backend/domain counterpart.
- **MOCKED**: Hardcoded or simulated dummy data. (*Currently 0 across runtime code*).
- **PLANNED_ONLY**: Documented in product roadmap or architectural ADRs but not yet implemented.
