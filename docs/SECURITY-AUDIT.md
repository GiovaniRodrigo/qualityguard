## 1. Webhook HMAC & Replay Attack Defense

### Implementation Details
- **Cryptographic Hash:** HMAC-SHA256 implemented in `integrations/github/src/webhook.ts` and `integrations/github/src/governance.ts`.
- **Timing-Attack Resistance:** Employs `crypto.timingSafeEqual` over byte buffers of identical length, preventing side-channel timing disclosures.
- **Delivery Idempotency:** Tracks `x-github-delivery` headers via `store.recordWebhookDelivery(deliveryId)`. Duplicate webhook deliveries return HTTP 200 with `{ duplicate: true }` without re-running analysis or calling GitHub APIs.
- **Failure Behavior:** Requests with missing secrets, invalid headers, or signature mismatches return HTTP 401 Unauthorized immediately.

```typescript
// Example from webhook.ts
export function verifyGitHubWebhook(payload: string, signature: string | undefined, secret: string): boolean {
  if (!signature?.startsWith('sha256=')) return false;
  const expected = createHmac('sha256', secret).update(payload).digest('hex');
  const actual = signature.slice(7);
  return actual.length === expected.length && timingSafeEqual(Buffer.from(actual), Buffer.from(expected));
}
```

## 2. Git Injection & Sandbox Isolation

### Attack Vectors & Mitigation Matrix

| Attack Vector | Threat Scenario | Mitigation in `SandboxedRepositoryCloner` | Status |
| :--- | :--- | :--- | :--- |
| **Command Injection** | Injecting `; rm -rf /` or backticks into repo URL or branch | Regex character blocklist `/[;&|`$\n\r\t"'<>\0]/` + URL parser | **DEFENDED** |
| **Git Option Injection** | Starting repo/branch with `--upload-pack` or `-o` | Strict check: URLs and branch names cannot start with `-` + `--` delimiter | **DEFENDED** |
| **Protocol Smuggling** | `file:///etc/passwd`, `ssh://`, `ftp://` schemes | Enforces `https://` protocol only; `-c protocol.file.allow=never` flag | **DEFENDED** |
| **Submodule Hijacking** | Malicious `.gitmodules` pulling private network hosts | `-c submodule.recurse=false` + `--recurse-submodules=no` | **DEFENDED** |
| **Disk Exhaustion (Zip Bomb)** | Massive repo filling worker storage disk | 50MB disk quota check post-clone via recursive directory walk | **DEFENDED** |
| **Timeout DoS (Hang)** | Slow-loris clone or hanging git connection | 45-second hard process timer sending `SIGKILL` to git child process | **DEFENDED** |
| **Directory Traversal** | Branch names with `../../root` | Path traversal sequence `..` strictly prohibited in branch validator | **DEFENDED** |
| **Workspace Collision** | Concurrent jobs writing to same folder | Unique UUID-scoped workspace: `join(tmpdir(), 'qualityguard', 'workspaces', 'job-${UUID}')` | **DEFENDED** |
| **Dangling Workspaces** | Crashed or failed analyses leaving files | `finally` block and error catch handlers run `rm(dir, { recursive: true, force: true })` | **DEFENDED** |

## 3. API Multi-Tenant Authorization & Credentials

### Password Security & Cryptography
- **Hashing Algorithm:** `scryptSync` with 16-byte cryptographically secure random salt generated via `crypto.randomBytes(16)`.
- **Hash Format:** `<salt-hex>:<hash-hex>` (32 bytes derived key).
- **Password Verification:** Constant-time comparison using `crypto.timingSafeEqual`.
- **Password Policy:** Minimum 8 characters enforced at registration.

### JWT Token Management
- **Format:** Standard 3-part Base64URL JWT (`header.payload.signature`).
- **Signature:** HMAC-SHA256 using `QUALITYGUARD_AUTH_SECRET`.
- **Production Guard:** Throws an explicit fatal error on startup if `QUALITYGUARD_AUTH_SECRET` is missing in `NODE_ENV=production`.
- **Expiration:** 7-day fixed expiration (`exp`), verified against current server epoch timestamp.

### Rate Limiting & Brute-Force Protection
- Authentication endpoints (`/auth/register`, `/auth/login`) are protected by an in-memory IP sliding bucket limiter allowing max 100 requests per 60-second window.
- Exceeding limit returns HTTP 429 Too Many Requests with `Retry-After: 60`.

## 4. SQL Injection & Database Isolation

- **Query Sanitization:** 100% of SQL queries executed against Postgres in `apps/api/src/db.ts` utilize parameterized placeholders (`$1, $2, $3, ...`).
- **Dynamic SQL:** Zero string concatenation or template literal query generation.
- **Relational Integrity:** Foreign key constraints with `ON DELETE CASCADE` prevent orphaned records across organizations, projects, and reviews.

---

## 5. AI Prompt Injection & Finding Validation

- **Output Validation:** Findings generated by AI models in `packages/ai` are parsed and strictly validated against Zod schemas (`FindingSchema`).
- **Type Guarantee:** Unstructured model text is never directly inserted into database records; fields (`severity`, `category`, `status`, `decision`, `score`) are constrained to valid enum literals.
